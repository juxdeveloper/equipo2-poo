# equipo2-poo

Repositorio colaborativo para la materia de **Programación Orientada a Objetos**, enfocado en el desarrollo de ejercicios, prácticas y proyectos utilizando **Java**.

El objetivo de este repositorio es centralizar el trabajo del equipo, mantener un historial claro de cambios y organizar las entregas realizadas a lo largo del curso.

---

## Contenido del repositorio

Actualmente, el repositorio está organizado principalmente por carpetas correspondientes a cada práctica.

Ejemplo:

```text
equipo2-poo/
├── practica_01/
├── practica_02/
├── practica_03/
├── ...
└── README.md
```

Dentro de cada práctica pueden encontrarse:

* Código fuente en Java.
* Archivos necesarios para la ejecución de los programas.
* Reportes elaborados en LaTeX.
* Imágenes, diagramas o recursos utilizados en la documentación.

Además de las prácticas, el repositorio podrá incluir ejercicios y el proyecto desarrollado durante el curso.

---

## Tecnologías utilizadas

* **Java** — lenguaje principal para el desarrollo de los ejercicios, prácticas y proyecto.
* **LaTeX** — utilizado para la elaboración de reportes.
* **Git** — control de versiones.
* **GitHub** — colaboración y almacenamiento remoto del repositorio.
